A simple C# Windows Forms application that demonstrates object-oriented programming by allowing users to input information about a phone (such as brand, design model, and price). The application creates a Phone object from the input data and displays the stored information back to the user in a formatted way, including customized display (e.g., formatting price with currency symbols).

This project focuses on OOP principles, class creation, and interaction between user input and object data in a graphical interface.
